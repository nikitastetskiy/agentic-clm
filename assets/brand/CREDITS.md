# Brand logo overlay — source & license

`hashicorp-ibm-gradient.png` is the **"HashiCorp / An IBM Company"** lockup with its letters filled by
the HashiCorp brand gradient (blue → purple → pink → orange — the same gradient as the deck's
"Featured / In Person Events" divider) plus a soft shadow, on a transparent background. The deterministic
event editor places it in the bottom-left corner of each featured-event hero photo (slides 18–22).

- Generated by `scripts/gen_brand_logo.py` (re-run it after changing the source, gradient, or tagline).
- Source wordmark: `_src/hashicorp-logo-pd.png` — [HashiCorp Logo](https://commons.wikimedia.org/wiki/File:HashiCorp_Logo.png),
  Wikimedia Commons, **public domain**. Recolored and gradient-filled here.
- "An IBM Company" tagline is set in a system sans-serif at generation time.
- First-party branding used on HashiCorp's own internal deck.
